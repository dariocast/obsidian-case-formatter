# Changelog

## 1.0.0 — 2026-10-14

- Four conversions for selected text: UPPERCASE, lowercase, Sentence case, and Capitalize Each Word.
- Command palette actions, configurable hotkeys, and editor context menu items.
- Multiple selections, Unicode characters, and selection retention after conversion.
- Native Undo/Redo with a separate step for each conversion.
- Installable package, manual test note, and automated tests.
