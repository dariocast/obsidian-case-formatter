# Changelog

## 1.0.1 — 2026-10-14

- Prepare the community submission with an exact `1.0.1` release tag.
- Add official Obsidian ESLint checks to the verification pipeline.
- Clean the packaging destination so stale files cannot enter release archives.
- Add packaging regression tests and a repeatable desktop acceptance script.
- Verify commands, selections, native history, menu callbacks, lifecycle cleanup, and an assigned hotkey in Obsidian 1.14.4.
- Keep the Case Formatter name and document the naming and submission checks.

## 1.0.0 — 2026-10-14

- Four conversions for selected text: UPPERCASE, lowercase, Sentence case, and Capitalize Each Word.
- Command palette actions, configurable hotkeys, and editor context menu items.
- Multiple selections, Unicode characters, and selection retention after conversion.
- Native Undo/Redo with a separate step for each conversion.
- Installable package, manual test note, and automated tests.
